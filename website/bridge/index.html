What happens if delivery is delayed?

The transfer remains in flight while CCIP delivers it. Failed destination execution can be retried through CCIP. Source tokens cannot be unilaterally refunded after sending, because their destination message may still execute. Keep the source receipt and message ID.

What secures the bridge?

Both contracts accept finalized messages only from the configured CCIP router and the fixed bridge peer. The BNB contract has no administrator mint function. The bridge still depends on CCIP’s verification, the correctness of these contracts, and correct initial peer configuration.
