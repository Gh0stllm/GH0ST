Is the activity on this site live?

No. Build 001 is an interactive architecture and research explorer. The execution theatre is a frontend illustration based on the controller's source-level events. It is not a replay of blockchain receipts. A production activity feed requires verified deployment addresses, ABIs, an RPC connection, historical log recovery, and transaction receipt handling.

Where would the computing power come from?

For the proposed on-chain runtime, blockchain nodes execute the contract instructions. A transaction supplies the work request and pays for execution. The browser draws this interface; it does not make the planned model on-chain. The published controller uses a scripted fixture in its integration tests, and the complete model runtime is still being developed.

Can the agent spend without permission?

The implemented controller restricts native-currency transfers to owner-allowlisted recipients, enforces both a per-transfer cap and a cumulative run budget, and bounds action counts. The owner authorizes new runs and can cancel a running job. The current code does not provide arbitrary protocol calls or token approvals. These controls do not substitute for an independent audit.

What does the six-bit number represent?

It describes the selected export in the recovered six-bit research snapshot linked above. It is not a claim that this website is running a six-bit language model, nor that all later unpublished optimization work is included. Model weights, engine deployment, and complete inference costs are distinct from the small controller and clone costs.
