# Exact full-sentence kernel, local version 2

This variant retains the full 1,235,968-parameter SimpleStories V2 Q12 model, all four layers and all 4,019 vocabulary rows. It uses the same 282 verified executable weight tiles as `../codeweights/`, with the same pinned code commitment:

```
0x12677213f35fafa47dd7ba36ada796d0cff9f67a3a3dd58a2330348da10295ed
```

The version-2 changes remove redundant work and unused memory:

- Query/key/value projections reuse one packed normalized input vector. Gate/up projections also share their input packing.
- The cache is invalidated after every RMS normalization, and switching to an attention or SwiGLU vector forces a fresh packing. These arrays have fixed, distinct internal pointers and dimensions; no approximate hash lookup is used.
- Cached generation initially reserves only 256 bytes for embedding and normalization weights. A 185,504-byte matrix buffer is allocated only if an input requires the exact non-tile fallback.

No learned weight, arithmetic equation, vocabulary entry, output token or stopping rule is changed. `generateSentence` stops only on the model's own native period, exclamation mark, question mark or EOS. Reaching its token cap is reported separately as incomplete.

The local real-Uniswap-v4 test completed **“some are good.”** as four newly generated tokens in one swap at **28,368,333 gas**; a repeat used **28,345,827 gas**. It completed **“he said.”** as three newly generated tokens at **21,388,483 gas**. The initial prompt in each case was punctuation, so the words and terminal punctuation were generated by the model. With the connective prompt “Because”, it generated **“everyone was happy.”** in one swap at **28,374,622 gas**. These are bounded short-sentence results, not a guarantee that every prompt or longer sentence fits 32 million gas.

The executable weight representation increases deployment/code storage. Both packed fallback data and code tiles are retained. Deployment costs are separate from the measured swap costs. The model is still a small story model, and this optimization does not improve its general question-answering quality.

The exact tile exporter, coverage and signed-arithmetic proofs are in `../codeweights/`. Full model and swap verification is recorded by the neighboring benchmark harness. This experiment uses an isolated local Anvil chain only. No mainnet or GitHub action is part of this version's work.
