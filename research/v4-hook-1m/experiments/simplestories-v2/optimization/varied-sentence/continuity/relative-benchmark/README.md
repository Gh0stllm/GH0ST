The hook requests two tokens while the processed count is at most 26, then one token. Native punctuation or EOS may end a two-token chunk early. Each swap adds genuine model-generated tokens; a swap can emit a fragment and does not promise a whole sentence.

## Continuity

The model persists raw numerical keys and values for each layer after successful swaps. At each new position it attends to the newest 64 positions, including the current position. A relative rotary transform uses ages 0–63, so it no longer indexes a finite table by the lifetime position. Old keys are not repeatedly rotated or recomputed. The pending token and global sampling step continue across punctuation and EOS.

The learned weights are unchanged. Relative key rotation uses a different Q12 rounding path from the earlier absolute-position variant, and has its own independent numerical reference. This test proves that implementation's parity, not bit-for-bit equivalence to the previous variant or a floating-point model.

## State and safety checks

Hook data is exactly 96 bytes: ABI-encoded `uint64 revision, bytes32 expectedContextHash, bytes32 seed`. Every preview matched the next actual swap, including its next context hash. Stale revision/hash, forged context, malformed data, unauthorized callbacks, low gas, changed model code, and tampered active KV code were rejected. A forced router revert after inference/settlement rolled back the story, hook, pool, and balances. EOA-owned model state and a second pool remained isolated from the tested pool.

The model uses uint64 counters and version 2 KV headers containing an eight-byte start position. There is no 2,048-position table stop. The counters are finite at 2^64; this is a practical bound, not mathematical infinity. Active inference reads a bounded 64-position suffix, while historical KV contracts and their indices accumulate over time.

## Reproduce and scope

From the research repository root:

```sh
node experiments/simplestories-v2/optimization/varied-sentence/continuity/relative-benchmark/run-local.mjs
node experiments/simplestories-v2/optimization/varied-sentence/continuity/relative-benchmark/finalize.mjs
```

The runner starts its own loopback Anvil chain 31337, validates chain identity before every mutation, uses direct receipt polling, and shuts down its own node. It injects validated immutable weight/table/tile code to save setup time, so shard deployment cost is excluded. Story KV state is generated by actual successful swaps. Compiler reuse requires an exact match of compiler, settings, entrypoints, and all source hashes; fresh model bytecode matches the separately compiled artifact.

This remains a local research adapter whose constructor rejects other chains. The gas figures cover one fixed-seed trajectory with test ERC-20s on an unforked chain. They are not live Robinhood fees, a worst-case gas proof for every possible story, or a broad prose/uniqueness evaluation. No public transaction was submitted.
