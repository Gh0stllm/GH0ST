Base directory: recovered-model/research/v4-hook-1m/experiments/multichain-gpt2
No existing model files are to be changed. Research branch: research/multichain-gpt2-124m.
Goal: actual full GPT2 124439808 parameter integer inference partitioned across 4 EVM instances; no mock math in full benchmark.
Default route: stage0 Robinhood(4663,EID30416) EMBEDDING ONLY (range0..0); stage1 BNB(56,EID30102) BLOCKS0..3 (range0..4); stage2 Monad(143,EID30390) BLOCKS4..7 (range4..8); stage3 Arc(5042,EID30417) BLOCKS8..11 + normalization/full vocabulary head (range8..12).
