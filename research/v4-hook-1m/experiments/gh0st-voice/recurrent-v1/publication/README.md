# Recurrent experiment publication snapshot

This staged update preserves completed local research on the ReLU recurrent model, exact fused input projection, and GRU feasibility, together with the frozen data-v2 preparation, original voice passages and independent language reviews. It is an incremental addition to the existing `research/v4-hook-1m` repository tree, not a standalone dependency distribution.

Run `publication/restore.py --repo-root PATH_TO_GH0ST_CHECKOUT` to expand the three gzip corpus splits and completed-evidence archive back to their original paths. Every restored file is checked against its size and SHA256 and differing files are never overwritten. Source code and small explanations are visible without restoration.

The same command then reconstructs data-v3's three full splits from restored data-v2 plus the frozen `training/data-v3/additional.jsonl`, checking their original hashes. This avoids uploading duplicate full corpora. Data-v3 counts, vocabulary, manifest and additional rows are included directly. Its original 80-document source pack is retained under `data/voice-long-b.jsonl`; `gru-h224/training/prepare_voice_phase.py` provides the complete source-to-extension procedure. To rerun that procedure, use a new output directory with `--base training/data-v2 --extra data/voice-long-b.jsonl --output training/data-v3-rebuilt`, relative to `recurrent-v1`.

The selected experimental keeper is GRU voice-v3 checkpoint-08253456. Its float weights, configuration, metadata and probe are included, along with every selected Q10 export artifact. The original embedding/input-projection/bias files in that export are marked reference-only: they verify exact fusion and are not resident deployment data. This selection is not approval of language quality. All other model weights, every optimizer file, unrelated packed tensors, executable tiles, caches, environments and raw upstream corpora are excluded. Active training runs are listed and excluded in the restore manifest. Existing baseline model artifacts and Node/Python/Foundry dependencies remain prerequisites for reproducing historical feasibility tests.

Technical parity and gas measurements are separate from language quality. The completed ReLU experiments do not meet the requested coherent first-person voice. Read the independent evaluation reports and per-source validation before considering a model for release. No public-chain transaction is part of this snapshot.

The selected GRU completed 128 local swaps, with one emitted word per swap and maximum gas22,280,162. Its independent integer reference passed. The raw EVM report intentionally retains its earlier `EVM_PASS_AWAITING_INDEPENDENT_REFERENCE` status because its bytes are hash-bound; read it together with the separate `selected-voice-128-reference.json`, final summary and `SELECTED-VOICE-RESULTS.md`. Do not rewrite historical evidence to make its status look newer. The final conclusion remains that gas/emission/parity passed locally while language quality was not approved.

`data/DATA_OPTIONS.md` is discovery research, not permission to ingest the linked corpora. No new external corpus was added to training during that review.
