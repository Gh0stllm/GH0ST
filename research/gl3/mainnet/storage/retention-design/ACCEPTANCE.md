# Retention design · required acceptance

**All items below are future gates. No test was executed by this design lane.** Tests must run on isolated Runpod paths, preserve existing selected/frozen machines and avoid public transactions or real pruning. A native pass cannot certify a changed guest/root.

| Gate | Concrete evidence required | Reject / stop condition |
| --- | --- | --- |
| Protocol and source freeze | Separate format/fork identifier, exact native/guest sources, unchanged engine/NNUE/search identity, precise bank/header/bitmap domains, fixed finite slot universe | Alias with A14/A15/seed, mutable cells routed through an unreviewed immutable-only reader, or hidden strength change |
| Ownership and dust | Real StateDB cells with zero/nonzero nonce and donated balances; overwrite/reset preserves nonce, balance and unrelated storage exactly | Nonce reduction, balance burn/redirect, SelfDestruct or deletion justified merely by blob ownership |
| Shared admission | Real EVM calls to each simultaneously enabled chess profile and one common heavy-operation/admission budget | Two active games or duplicated heavy work admitted through different profile addresses |
| Complete image | Initial, suspended and completed real images; memory growth; unchanged full memory/globals/TT/history/control state; existing incremental tree root | TT reset, omitted zero transitions, cleared pending state, root or canonical-byte mismatch |
| Page semantics | First/last page, seed-equal page, nonzero-seed→zero override, zero-extension growth, present/missing bitmap, stale/wrong epoch/index/module/header, malformed/trailing bytes | Missing referenced page accepted as seed; page outside active bounds used; old-job page affects new image |
| Atomic transition | Real EVM and committed StateDB root before/after successful step; exact dirty cells, bitmap and metadata; no unjournaled authoritative state | Partial page/descriptor mix becomes reachable |
| Failure and rollback | Trap, malformed input, OOG one gas short, injected write failure at each write boundary, outer contract revert, same-block repeated overwrite | Code bytes/root/nonce/balance/bitmap differ from pre-transaction snapshot after revert |
| StateDB variants | Snapshot/revert, Copy, commit/reopen and independent StateDB views with dirty/current/historical code versions; real code journal/witness checks | Dirty code bypassed, wrong prior code journaled, cache state decides validity |
| Cache ABA | Same namespace/root under changed epoch/backing; branch A→B→A with equal counters but different legitimate page contents; reverted switch; cold and warm executions | Host cache makes a valid cold state revert or uses another branch's VM/code identities |
| Observer/RPC lifecycle | Actual handler calls blocked at restore/use/Close; concurrent RPC, observer recording, cancellation before/while waiting and during restore, failure cleanup, idempotent lease release | Lease released before use/Close, leak, duplicate memory admission, live-cache mutation or skipped proof dependencies |
| Metering and cadence | Exact warm/cold/observer gas and resulting block/receipt hashes; worst dirty-page writes, maximum memory, current configuration ceilings; measured block and cold-recovery distributions | Different consensus gas by cache state, underpriced/unbounded cold work, or ordinary blocks blocked beyond accepted target |
| Guest replay | Fresh separate bank-profile machine; native/guest all-four global-state and gas equality for actual engine-bearing transitions, exact raw interpreter halt steps and real exit 0 | Diagnostic-only success, sampled counter, mismatched source/root, timeout/OOM or any end-field mismatch |
| One-step and lifecycle | Real selected bank-profile witnesses and corruption negatives; exact terminal interval, rival assertions, full on-chain dispute binding, confirmation and exact collateral receipt with independent auditor | Old865/eager/A15 result substituted; unrelated edge/refund; privileged/mock completion or premature Geth cleanup |
| Ring alternative only | Proven no-overwrite watermark and sufficient worst-case ring bound, or actual exact suspended-image checkpoint/continuation before ring fills | Ring exhaustion truncates/restarts/reduces search or overwrites a live source/build dependency |
| Retirement alternative only | Real cross-job/cross-profile shared bodies, canceled builds, reattachment/resurrection, bounded cursors, code identity checks, reverts/crashes and preserved predecessor | Clearing a shared/live/seed/unexpected cell; corrupt reference counts; clearing needed traversal metadata first |
| Historical availability | Exact retained-root/dependency inventory covering unresolved assertions/edges and reorg/finality/recovery obligations; code-hash union across accounts/epochs | Missing module/seed/batch/trie/code/terminal input, arbitrary age cutoff or per-account code deletion |
| Independent recovery | Archive manifest/hash verification and a second fresh restore/replay path; corrupt/missing archive negatives; measured retrieval + proof response within real deadlines | Private unavailable genesis, archive completion assumed from upload alone, or recovery outside dispute deadline |
| Physical retention rehearsal | Only after separate authorization: disposable copied database; actual before/after disk bytes, all pinned roots still readable, retained proof inputs replay, crash/restart recovery | Current-state bound called disk reclamation, live DB pruned, or code shared by another protected root lost |
| Capacity and cost | At least 20 real full-strength games under declared sequential/concurrent policy and accepted later-game lengths; CPU/RAM/1 TB disk, DB amplification, archives/replicas/egress and actual hosting quote | First decision or arithmetic bound presented as 20 games, $100/month, zero downtime or 1 TB acceptance |

## Release packet boundaries

Publish source/machine/input hashes, actual process exits, resource measurements, raw receipts, named-test completions and independent audit results. Preserve older failures and stopped trials. A design, encoded image, native integration, JIT diagnostic, full interpreter replay, witness test and completed real BoLD lifecycle remain distinct milestones.

The fixed-bank change affects STF state layout, mutable code reads/writes and proof inputs even when Stockfish itself is byte-for-byte unchanged. It requires a new reviewed root. It cannot inherit the selected865 machine's acceptance or any older eager/lazy result.
