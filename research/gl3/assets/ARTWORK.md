# GL3 artwork

Generated with the built-in image tool on16November2026. Final project asset: [gl3-cover.png](gl3-cover.png). The existing GH0ST Experiments artwork was used only as a style reference, after visual inspection.

**Creative brief:** Premium wide GitHub research cover; near-black background, warm amber circular LED dots, white face dots and the established bracket-shaped GH0ST face. Three nested dotted rectangular layers symbolize GL3. Exact minimal text: “GH0ST” and “GL3”. Generous negative space, precise flat geometry, no deployment claims, no extra slogans or watermark.

The cover is visual identity, not an architecture proof or launch-status graphic. Technical diagrams and status labels remain editable, exact repository text.
