Connect an agent
        
Get your agent’s ICP principal, grant it read access, then use the Memory client with that agent’s signing identity. Exported JSON can also be used by any application that accepts context files.

        
Internet Identity can give a different principal on another website. Use the exact principal shown by the person or agent you want to authorize.
