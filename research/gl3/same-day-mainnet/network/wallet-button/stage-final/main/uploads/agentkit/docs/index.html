02 / ONE STEP AT A TIME

A bounded
commitment.

01  Check the reviewed deployment.
02  Connect the registered owner wallet.
03  Read the on-chain GH0ST fee policy.
04  Review an exact, bounded token approval.
05  Deposit into the agent budget separately.
06  Submit a public prompt and reserve its fee.
07  Track the confirmed result or eligible refund.

Approval sets only an exact token allowance; it does not fund a request. Deposit and request are separate reviewed transactions. Every step shows chain, target and amount before the wallet opens. Robinhood network gas is paid separately in ETH.

03 / JAVASCRIPT SDK

Your application.
Shared infrastructure.

npm install https://gh0st.fyi/Agentkit/downloads/gh0st-agent-kit-0.3.0-alpha.1.tgz
import { GH0STPaidClient } from '@gh0st/agent-kit/paid';
import { inspectPaidManifest } from '@gh0st/agent-kit/paid/manifest';

const access = inspectPaidManifest(reviewedDeployment);
if (!access.activationReady) {
  throw new Error('Paid access is still in preparation.');
}

// After the owner explicitly connects their wallet:
const paid = new GH0STPaidClient({
  provider, signer, manifest: access.manifest
});
const quote = await paid.getQuote(registeredAgentId);
// Show the on-chain quote before any wallet action.

The SDK reads the quote and fee policy directly from the pinned contract. It verifies runtime hashes, token decimals, model/artifact/signer bindings and admission. It never assumes a deployed payment address or a service price.

Use prepareApproval, prepareDeposit and prepareRequest to build separate reviews. Only executeTransaction(plan, { execute: true }) can request a wallet transaction. The SDK rereads the account, chain, deployment and intent immediately before signing.

04 / ACCEPTANCE & REFUNDS

Know what
is reserved.

Prices come from the reviewed payment contract.

Before acceptance:
  The full reservation is refundable.

After acceptance:
  The disclosed acceptance charge may remain
  even when no answer is delivered.

Refunds return to the agent budget.
Owner withdrawal is a separate transaction.

Robinhood network gas is paid separately in ETH.

The configured operator accepts work on-chain before paid compute begins. A fulfilled request charges the full service reservation. An accepted request can retain its disclosed acceptance charge even when no answer is delivered.

Refunds credit the agent budget. The owner can withdraw available, unlocked funds separately. New-request pauses do not remove those exits while the deployment pins remain valid.
