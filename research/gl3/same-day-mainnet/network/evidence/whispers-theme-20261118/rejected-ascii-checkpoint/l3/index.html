06 / THE DETAILS MATTER

A few things
worth knowing.

Is this a new GH0ST token?+

No. The bridge escrows the existing ERC-20 GH0ST on Robinhood and credits native GH0ST on GL3. Native GH0ST pays gas. It is another representation of the same backed asset, not additional unbacked supply.

How do deposits and withdrawals work?+

Deposit: approve an exact GH0ST amount, then deposit through the Robinhood Inbox. The same externally owned wallet receives native GH0ST after parent-chain processing. Withdraw: burn native GH0ST on GL3, wait for a GH0ST-confirmed withdrawal root, then claim the backing token on Robinhood. Save your withdrawal hash; the bridge can recover its proof.

Is there a seven-day withdrawal wait?+

The normal GH0ST fast-confirmation path does not impose that fixed challenge wait. The GH0ST operator must first confirm the root on Robinhood. It is not instant or trustless. A standard challenge-period fallback may remain in the contracts. Network processing and Robinhood claim fees still apply.

Is this secured by ZK proofs today?+

No. This launch uses Nitro with project-run validators and a trusted fast-confirmation key. ZK verification, full Stylus execution proofs and LLM validity proofs remain research. None of them secure this launch.

Does every block take 100 ms?+

100 ms is the configured minimum block-production interval when transactions arrive, not a settlement guarantee. Blocks are demand-driven. Automated demonstrations are not organic adoption or throughput measurements. RPC latency, batching and parent finality are separate stages.

What if GH0ST infrastructure goes down?+

Sequencing, batch posting or fast confirmation can pause until the operator recovers. Durable node storage does not guarantee uninterrupted service. Keep transaction hashes and check actual status before sending more funds.

What are the demo tokens and NFTs?+

Demonstrations may include transfers, test contracts, test ERC-20 tokens and NFTs. They show real execution. They are not organic-user volume, audited products or tokens with promised value.

Can I use my normal EVM tools?+

Yes. Add chain ID 4663001, use the public RPC, and pay gas in native GH0ST. The lightweight explorer shows actual blocks, transactions, receipts and balances. Advanced indexing and source verification are not part of the initial explorer.
