# GH0ST Scene Decoder · 500 KB

A model for generating **32 × 32 pixel-art scenes in one pass on Robinhood Chain**. The prompt selects two supported subjects, their colors and relative layout, a background, and a visual style. For example, “amber fox to the left of a blue crystal, snowy forest, stained glass.”

The style selects one of seven learned scene decoders. Each style learns its own scene layout and 128 image patches. The styles share the layers that refine the layout and select the patches. This lets the larger package specialize without evaluating all seven decoders for every image. Style IDs select the decoder deterministically, and the seed controls variation within the chosen prompt.

## Package

The 500,000-byte budget refers to serialized model data. The table excludes code for the inference contract, deployment prefixes, and the frontend prompt dictionary. Subject and background counts describe table capacity and still need training and validation.

| Component | Payload bytes |
| --- | ---: |
| Seven 96 → 1,024 scene projections, with five-bit weights and per-row scale and bias | 473,088 |
| Two shared 32-channel spatial mixing blocks and their scales and biases | 2,408 |
| Shared 32 → 128 patch classifier and its scales and biases | 3,328 |
| Seven 128-entry dictionaries of 4 × 4 patches with five-bit palette indices | 8,960 |
| Sixteen 32-color RGBA palettes | 2,048 |
| Up to 256 subject embeddings and 32 tint embeddings, each 24 signed bytes | 6,912 |
| Relation, background, style, and palette embeddings | 824 |
| Per-style 16-bit channel gains and offsets for the two spatial blocks | 1,792 |
| **Model payload** | **499,360** |
| Available for a versioned package header and shard manifest | **640** |

On-chain storage can use one immutable bytecode shard per 67,584-byte style projection and an eighth shard for the shared data. A versioned registry would bind the shard hashes. One image reads only the chosen expert, including its patch dictionary and style gains, plus the shared parameters it uses.

## Inference

Each of the two 24-value subject embeddings incorporates a tint. Four eight-value embeddings represent the relation, background, style, and palette. A further 16 values come from the seed and canonical prompt, for 96 inputs in total.

The selected scene decoder produces two responses for each channel at each cell of a 4 × 4 × 32 grid. Pairwise maxima reduce that to one response per channel. The grid upsamples to 8 × 8, with two spatial mixing blocks and the selected style's per-channel gains and offsets. The patch classifier scores 128 entries for each output cell, selecting the first entry in ties. Each selected patch contains 16 five-bit indices for the chosen palette. The complete image is 640 bytes of packed indices plus a palette ID. The same model version, prompt fields, and seed must reproduce the same bytes.

| Stage | Active multiply-accumulates per image |
| --- | ---: |
| One scene projection | 98,304 |
| Two 3 × 3 depthwise and 32 → 32 pointwise spatial blocks | 167,936 |
| 32 → 128 patch classifier on 64 cells | 262,144 |
| **Total** | **528,384** |

## Robinhood gas test

Read-only simulations at block 121608045 used synthetic five-bit weights. Each of the three dense-layer shapes returned the same values as an independent integer calculation. The estimates include the standalone calls' overhead.

| Layer | Calls per image | Gas per call |
| --- | ---: | ---: |
| Selected scene projection, 96 → 512 per slice | 2 | 2,215,082 |
| Shared pointwise mixing, 32 → 32 on 64 cells | 2 | 1,294,450 |
| Shared patch classifier, 32 → 128 on 64 cells | 1 | 4,555,017 |
| **Dense subtotal** | | **11,574,081** |

The subtotal corresponds to **0.000253912188978 ETH** at the sampled 21,938,000 wei per gas. The benchmark excludes depthwise convolutions, rescaling, biases, conditioning and seed work, style gains, output assembly, and persistence. One full transaction must fit Robinhood's measured **32,000,000 gas** ceiling. The estimates and exact-output checks are in [the benchmark evidence](robinhood-dense-500kb.json). Reproduce the simulation with `node benchmark.cjs --500kb` using Solidity 0.8.30 and ethers 6.

## Evaluation

Train on original or expressly licensed art with style and composition labels. Test the learned patch dictionaries on held-out art before training the full generator. Compare subject recognizability, layout, color, and visual preference against the [original 80 KB design](README.md) using held-out subject pairs and artwork. Report per-style results. The original 19.7 KB sprite decoder gives a baseline on its supported prompts.

Use exactly the same quantized weights and prompt encodings in the reference and the EVM. Measure the complete image against Robinhood's transaction cap after training and verify exact output hashes across all seven styles. The current package budget is a design calculation. Trained weights, visual samples, and complete-image gas are pending.
