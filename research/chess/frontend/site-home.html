What is actually verified?−

S0UL mainnet generation and a bounded memory action. A readable RH → ICP → RH pilot. A one-token GPT-2 round trip through opBNB. Each is a different execution path, with separate proof links.

Where does trust remain?+

The ICP route depends on canister controllers and source-chain RPC providers. Robinhood checks a threshold-signed result; it does not independently prove every model operation. Transport is asynchronous.

How good are the models?+

Correct execution is not the same as a good answer. S0UL is a constrained model. The ICP output demonstrates one completed route. The opBNB output was a newline, and a longer follow-up did not complete.

What is current, and what is a snapshot?+

The evidence snapshot was prepared on 26 October 2026. The transmission panel can check the public Robinhood gateway for newer confirmed output. Research branches may retain older deployment notes; transaction links identify the recorded executions.
