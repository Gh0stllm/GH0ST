# Trained SYNAPSE micro-model

This is a real, tiny next-token neural network trained from scratch with NumPy backpropagation. It is a reproducible module-composition demonstration, with a vocabulary of 30 tokens, a context of exactly two tokens, hidden width 8, two parallel experts, and a shared output head. The base model has 894 scalar parameters. It is not an LLM or evidence of broad language understanding.

`corpus.json` contains 18 original synthetic phrases (CC0-1.0), their provenance, and no external or pretrained data. The script produces 84 next-token examples, including sentence boundaries. All three experts, including the alternate, were trained by the same GH0ST SYNAPSE project. No independent-contributor authorship is claimed.

## Reproduce and check

From this directory, with Python 3 and NumPy installed:

```sh
python3 train.py
python3 reference.py
python3 -m unittest test_reference.py
```

The seed is `5102026`. Base training uses 7,000 full-batch Adam steps; alternate training uses 5,000 steps with only expert 1 trainable. The implementation uses explicit NumPy tensor contractions and float64 arrays. The exported JSON records the NumPy version; byte-identical reruns are checked in the current environment, while other NumPy/platform versions may differ. Runtime inference and fixture checks need only the Python standard library.

## Exact integer arithmetic

All exported parameters are signed integers with scale 256. Quantization rounds to nearest, ties to even. Tensor order is row-major, with matrix rows corresponding to output channels.

1. `hidden[j] = clip(E0[token0,j] + E1[token1,j], 0, 32767)`.
2. For each expert: `activation[o] = clip(tdiv(sum(W[o,j] * hidden[j]),256) + bias[o], 0, 32767)`.
3. `merged[j] = tdiv(expert0[j] + expert1[j], 2)`.
4. `logits[o] = tdiv(sum(headWeights[o,j] * merged[j]),256) + headBias[o]`.
5. Return the index of the largest logit, choosing the lowest index on ties.

`tdiv` truncates toward zero, including negative values. A dot product is summed before division. Logits have no activation or clipping. The activation bound applies to the backbone and each expert. No softmax is needed at inference. Token IDs are the indices in `vocab`; `<bos>` is 0 and `<eos>` is 1.

`model.json` contains `schema`, `id`, `scale`, `contextSize`, `hiddenSize`, `activationMax`, `vocab`, flattened `embedding0`/`embedding1` (30×8 each), two `experts` with `weights` (8×8) and `bias` (8), flattened `headWeights` (30×8), `headBias` (30), training provenance, and measured metrics. `alternate-expert.json` has the same expert tensor shape and names, plus `replaceExpertIndex: 1` and `compatibleModelSha256`.

## Measured result and limits

On the training corpus, the quantized base model predicts 62 of 84 examples correctly (73.81%), matching the maximum possible accuracy with only two input tokens. Several phrases have the same two-token context but different next tokens; there is no information in this architecture to distinguish them. Accuracy on contexts with a unique training target is 100%. These are training-set measurements, with no held-out generalization claim. Floating-point and quantized models have the same aggregate accuracy; ambiguous-context choices can differ after quantization.

Example exact-integer continuations:

```text
robinhood is → home <eos>
inference runs → on icp <eos>
ghost checks → proof <eos>
ghost builds → models <eos>
models learn → from tokens <eos>
```

The alternate expert changes the supported context `ghost checks` from `proof` (token 21) to `models` (token 17). Training freezes the exported backbone, expert 0, and shared head, then trains only expert 1 against an explicitly changed synthetic target. This demonstrates that a compatible trained module can alter output; it does not establish independent authorship or a general improvement. The replacement has 100% accuracy on deterministic contexts in its revised training targets.

`fixtures.json` records 63 full exact traces: 55 distinct observed base contexts and eight alternate-module contexts, including the changed output. Every trace includes hidden activations, both expert activations, merged activations, logits, and the chosen token. The reference checks artifact digests before comparing all traces. `test_reference.py` additionally checks hand-calculated signed division, activation clipping, odd means, ties, and module replacement. `manifest.json` records SHA-256 hashes of the exported corpus, model, alternate expert, and fixtures; it is regenerated by training.
