# GH0ST Echo

A playable co-op puzzle for Robinhood Chain. The game stores a previous run as moves. A second player submits their own moves, and the contract replays both sequences against the same fixed room rules. A win depends on their timing. The game needs no oracle, model service, or prize escrow.

This branch tracks the room, browser controls, contract, and verification evidence. A read-only mainnet rehearsal and a confirmed public onchain win are identified separately.
